## 한 것

- **단일 원장**: 국고가 바뀌는 23곳을 `gold()` 하나로 모으고 군량 증감도 분류해 기록한다. 주 마감 때 원장 합계와 실제 증감을 맞춘다. 세수는 엔진의 세수 줄 한 곳, 수확은 수확 사건 한 곳에서만 생기고 내정은 배율만 건다.
- **월간 결산·정비**: 달이 바뀌면 `(scenarioId, factionId, monthKey)`로 한 번 결산하고 `PAUSED_MONTHLY`가 된다. 이 상태에서는 `tick()`이 아무것도 하지 않는다. 정비 중 플레이어의 내정 명령은 예약되고(국고 예약 포함), 재개 때 정해진 순서로 재검증해 한 번 실행한다. 자동 정지를 끄면 결산 기록만 남는다.
- **임명 팝업**: 도시·국정·부대·월간 정비가 같은 `openPicker()`를 쓴다. 정렬·필터·검색, 적성, 지금 담당자 대비 효과, 떠나는 자리의 공백, 2단계 확인, Esc 순서, 포커스 가두기, 열기 전 상태 복귀.
- **주직**: 인물 한 명은 성주·부관·국정 담당관·부대 지휘 가운데 하나만 맡는다. 옮길 때 옛 자리 해제와 새 자리 등록이 한 명령 안에서 일어난다. 군주는 실무 보직 불가. 지역 성주(`Region.lord`)와 실무 성주는 따로 기록한다.
- **도시**: 5분야·중점 1개·시설 5종 Lv0~3(60/120/180, 4주, 유지비 Lv당 1). 빈 도시는 효율 1.0.
- **통치**: 직할/자치/독립 권한 판정, 행정 역량·부담·징수 효율·유지비, 불만 누적과 25/50/70/85 경고. 호족 거점 직할은 기존 귀부 약정의 조건을 고쳐 쓰고(상납 5할·동원 의무) `controller`는 바꾸지 않는다. 합의 직할은 기존 사신·협상 경로를 탄다.
- **국정**: MIL-01→MIL-02(중장보병 모집 해금), SOC-01→SOC-03(시행 시 역량 +2), PRJ-02(대상 거점 수확 +10%). 분야당 1과제, 담당관 필요, 예산 3단계를 주 단위로 나눠 내고 실제 낸 주만큼 진척.
- **AI**: 세력마다 주 1건의 내정 행동을 같은 `issueOrder`로 낸다.
- **세이브**: v3 → v4 순차 마이그레이션.
- **화면**: 영역을 세력 색으로 칠한 양피지 지도, 방패 문장, 금테 창, 오른쪽 세로 메뉴, 왼쪽 아래 군주 원형틀.
